# Shop Manager

Учебный проект: система учёта клиентов, товаров и заказов интернет-магазина
с графическим интерфейсом (tkinter), базой данных SQLite и визуализацией.

## Возможности

- Регистрация клиентов (имя, email, телефон, город)
- Добавление товаров (название, цена, категория)
- Создание заказов (клиент + товар + дата + количество)
- Проверка email и телефона через регулярные выражения
- Хранение данных в SQLite (сохраняются между запусками)
- Экспорт и импорт данных в форматах CSV и JSON
- Фильтрация и сортировка заказов по городу, датам и сумме
- Визуализация: топ-5 клиентов, динамика заказов, граф связей
- Unit-тесты на модули `models` и `analysis`

## Установка

```bash
git clone https://github.com/Inna12509/shop_manager.git
cd shop_manager
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Откроется окно с тремя вкладками: **Клиенты**, **Товары**, **Заказы**.

## Анализ данных

```bash
python analysis.py
```

Графики сохранятся в папку `exports/`.

## Тесты

```bash
python -m unittest discover tests -v
```

## Структура проекта

```
shop_manager/
├── models.py       — классы Client, Product, Order
├── db.py           — работа с SQLite, экспорт/импорт CSV и JSON
├── gui.py          — графический интерфейс (tkinter)
├── analysis.py     — анализ и визуализация
├── validators.py   — проверка email и телефона
├── main.py         — точка входа
├── seed.py         — скрипт заполнения базы тестовыми данными
├── data/           — база данных SQLite
├── exports/        — сохранённые графики и экспорты
└── tests/          — unit-тесты
```
